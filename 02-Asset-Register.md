# 02. Information Asset Register

## Purpose

Before assessing security risks, I need to identify what the firm is protecting, where each asset is held and who is responsible for it.

I've identified 12 important assets based on the fictional law firm's operations.

## Asset Register

| ID | Asset | Owner | Classification | Location |
|---|---|---|---|---|
| A01 | Client legal documents | Managing Partner | Restricted | Cloud document system |
| A02 | Client personal and financial data | Compliance Officer | Restricted | Cloud storage |
| A03 | Microsoft 365 tenant | IT Manager | Confidential | Microsoft Cloud |
| A04 | Employee laptops | IT Manager | Internal | Office / Remote |

| A07 | Client billing records | Finance Manager | Confidential | Finance system |

| A11 | E-discovery supplier service | Compliance Officer | Restricted | Third-party cloud |
| A12 | IT support access and records | IT Manager | Confidential | Outsourced IT provider |

## Classification Levels

- **Public:** Information that can be shared openly.
- **Internal:** Information intended for employees.
- **Confidential:** Sensitive business or employee information.
- **Restricted:** Highly sensitive information that requires the strongest protection.

## My Initial Findings

The firm's client documents, financial information and cloud document management system are particularly important because they contain sensitive client information.

A breach could lead to confidentiality issues, legal consequences and reputational damage.

The firm also relies heavily on Microsoft 365 and external suppliers. I'll examine these dependencies in the risk assessment.

## Assumptions

The assets, owners and classifications above are fictional examples. The locations and security arrangements would need to be verified in a real assessment.

Project Overview

This project looks at how a small London law firm could manage information security risks and prepare for an ISO 27001 assessment.

Harrow & Lane LLP is a fictional law firm with 60 employees. It uses Microsoft 365, a cloud document management system and external IT suppliers. One of its banking clients has requested evidence of its information security practices.

The aim is to work through the key responsibilities of a GRC analyst, including identifying assets, assessing risks, reviewing security controls and documenting findings.

I'll build each part of the project separately and explain the decisions behind my assessments.

Note: This is a simulated case study created for learning and portfolio development. It does not represent a real company or certified ISMS.

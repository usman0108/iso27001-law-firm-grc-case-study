# ISO 27001 GRC Case Study — Harrow & Lane LLP

## Project Overview

This is a self-directed GRC portfolio project based on a fictional 60-person law firm in London.

The firm handles confidential legal documents, uses Microsoft 365 and relies on third-party suppliers. The scenario involves a banking client requesting evidence of the firm's information security practices.

The aim of this project is to explore how a junior GRC analyst could identify security risks, review controls and prepare for an ISO 27001 assessment.

## Project Files

| Stage | Document | What It Covers |
|---|---|---|
| 1 | [ISMS Scope](01-ISMS-Scope.md) | Defines the systems, people and information included in the assessment |

## Key Areas Covered

- Information asset identification and classification
- Risk scoring and treatment planning
- ISO 27001:2022 Annex A control selection
- Third-party security risk assessment
- Audit evidence tracking
- Documentation of proposed security improvements

## Key Findings

The initial assessment identified several areas requiring attention, including phishing, inappropriate access to client documents, ransomware and supplier security.

In this scenario, I would prioritise reviewing access controls, multi-factor authentication and the firm's handling of confidential client information.

The proposed security controls would require evidence and testing before their effectiveness could be confirmed.

## Project Limitations

This is a fictional case study developed for learning purposes, with AI-assisted drafting and research. It is not a real security audit, and no live systems or suppliers were assessed.

The ISO 27001 control review covers 12 priority controls, not a complete Statement of Applicability. The remaining controls would need to be considered as part of a full assessment.
